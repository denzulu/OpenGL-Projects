# OpenGL / GLUT Graphics Projects

This repository contains a collection of 2D interactive graphics projects developed using **C++** and **OpenGL (GLUT)**. These projects demonstrate various computer graphics concepts including geometric transformations, event handling, state machines, and simple physics.

## Projects Overview

### 1. Hot Pursuit (Cop vs. Thief)
A storytelling-based game featuring a specialized **state machine**.
* **Key Features:**
    * Multiple game states (Intro, Chase, Win/Loss).
    * Complex rotatable objects (Cop car with active emergency lights).
    * Collision detection between the chaser and the player.
    * Vector-based movement logic.

### 2. Defend The Border
A tower defense style arcade game where the player defends against incoming tanks.
* **Key Features:**
    * Angle-based shooting mechanics using trigonometry (`sin`/`cos`).
    * Dynamic object management (bullets and enemies arrays).
    * Hit detection and score percentage calculation.
    * Timer-based enemy spawning system.

### 3. Look Up Look Down
An interactive scene demonstrating environment manipulation.
* **Key Features:**
    * Dynamic Day/Night cycle triggered by user input.
    * Scene switching (Airplane vs. Ship).
    * Interactive objects (Opening/Closing curtains with mouse clicks).

## 🛠 Technologies
* **Language:** C++
* **Library:** OpenGL / GLUT
* **Concepts:** OOP (Struct-based), Vector Math, State Management, Event-Driven Programming.
